# URL service

POST /api/urls accepts a string url and optional expiresAt. Omitted or JSON null expiry means no expiration. Supplied expiry must be ISO-8601 text with UTC offset, strictly later than one captured injected Clock instant and at most the smaller of shortener.max-expiry-days and seven days after it. Exactly the effective maximum is accepted. Nonpositive configuration is rejected at startup. The unchanged application.yml default of 30 is capped at seven by the service; the service property fallback is seven. UTC Z and +00:00 are accepted. Malformed text, non-string values, missing zones, non-UTC offsets and invalid boundaries return 400 before code allocation.

Creation returns 201 with code, shortUrl, url, createdAt and explicitly nullable expiresAt. Location and shortUrl use shortener.public-base-url, preserving configured path prefixes and ignoring client Host and forwarded headers. Destinations are preserved exactly. Analytics returns code, url, createdAt, clickCount, lastAccessedAt and explicitly nullable expiresAt, including after expiration. Analytics never increments counters.

GET /r/{code} returns 302 with the exact destination only when eligible at its captured Clock instant. Unknown links return 404. Expiry equal to or earlier than that instant returns 410 without Location. A schema-qualified PostgreSQL conditional UPDATE increments click_count once and sets last_accessed_at only for eligible links. A failed update is followed by a read to distinguish unknown from expired. The existing InjectedRedirectFaultFilter passes responses through. Controller tests retain the filter and 302 assertions. Independent HTTP verification must disable redirect following.

Existing protected migrations remain unchanged. V1 creates url_service and its urls table. V2 already adds nullable expires_at and expires_at_submicro; no duplicate migration is added. Existing rows remain non-expiring. Expiry is truncated to microseconds before JDBC binding, with its remaining 0..999 nanoseconds stored separately. Reads reconstruct the exact Instant. Redirect SQL compares timestamp and remainder lexicographically with strict greater-than, preserving equality and one-nanosecond boundaries. last_accessed_at records the captured evaluation time at microsecond precision.

Destination validation accepts HTTP/HTTPS destinations and rejects invalid hosts or ports, credentials, malformed escapes and raw or encoded controls. No destination network requests are made. Eight-character SecureRandom base62 codes retain five allocation attempts. Only structured PostgreSQL SQLSTATE 23505 metadata identifying url_service.urls.pk_urls_code permits retries. Unexpected failures return generic 500 responses; allocation exhaustion returns 503.

The supplied baseline has no active creation rate limiter. Its creation-limit-per-minute configuration does not activate one. This replacement preserves that behavior; the stated twenty-per-minute requirement remains unresolved until limiter identity and scope are defined.
